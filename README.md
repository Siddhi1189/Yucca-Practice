# Yucca Packaging Website

A frontend website recreation project inspired by the Yucca Packaging website. The project focuses on recreating the visual design, layout, typography, animations, hover interactions, and responsive behavior using HTML, CSS, and JavaScript.

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Custom Fonts
* Locomotive Scroll

## Features

* Responsive navigation bar
* Hero section with interactive cards
* Image and content sections
* Animated marquee sections
* About section
* Products section
* Custom solutions section
* Standards section
* Questions/FAQ section
* Interactive hover effects
* Footer with interactive elements
* Smooth scrolling
* Mobile-responsive layout

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Siddhi1189/Yucca-Practice.git
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the website

Open `index.html` directly in a browser, or use the **Live Server** extension in VS Code.

No backend or database is required.
